# Actualizar el repositorio con los ejercicios 1 a 4

1. Descomprimir este ZIP en una ubicación corta de Windows, por ejemplo `C:\TP2_nuevo`. Abrir la carpeta interna `PP_TP2_50730`.
2. Abrir ese proyecto en IntelliJ con JDK 21 y ejecutar `src/App.java`.
3. Comprobar que aparecen inscripciones aceptadas y rechazos por cupo, tres mensajes `FINALLY`, certificados, cantidades y costos por tipo, y líneas con `[main]` y `[EnvioTickets-...]` intercaladas. El resumen final debe indicar 14 tickets enviados en la simulación.
4. Guardar una captura legible de esa consola como `captura_hilos.png` dentro de `docs`.
5. En la página principal del repositorio `Franco-Nicolas-Baigorri/PP_TP2_50730`, iniciar sesión y elegir **Add file → Upload files**.
6. Arrastrar las carpetas **src**, **docs** y el archivo **README.md** del proyecto actualizado. Seleccionar su contenido desde la carpeta interna, de modo que se conserven las rutas `src/App.java` y `src/hilos/EnvioTicketsThread.java`.
7. Comprobar en la lista que estén los dos archivos nuevos: `src/hilos/EnvioTicketsThread.java` y `src/utils/Consola.java`. También deben estar las nuevas versiones de `App.java`, `Inscripcion.java`, `Actividad.java` y `EventoUniversitario.java`.
8. Confirmar en `main` con el mensaje **Completar ejercicios 1 a 4**. Los archivos con la misma ruta se actualizan; las capturas anteriores que ya estén en el repositorio se conservan.
9. Abrir en GitHub `src/App.java` y comprobar que contiene `finally`; abrir también `src/hilos/EnvioTicketsThread.java` y la nueva captura.
10. El enlace del campus sigue siendo el mismo porque el repositorio no cambia.

La carpeta `events` y las salidas compiladas `cls` y `out` son generadas por la ejecución; los archivos a subir son los indicados en el paso 6.
